# FAQ

## What is this repository?

It contains independent demos and experiments for Amazon Bedrock AgentCore. See the [repository index](../README.md) to find a topic.

## How do I run a demo?

Choose a numbered directory and follow its instructions. [CONTRIBUTING.md](../CONTRIBUTING.md) describes the general setup.

## What do I need, and will it cost anything?

Requirements vary by demo; most need AWS credentials with AgentCore access. Many create AWS resources that incur charges, so follow the demo's cleanup instructions when finished.
